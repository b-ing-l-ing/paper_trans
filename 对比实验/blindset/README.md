# blindset —— 无印值柱状图盲测集

「代码读图 vs LLM 读图」的盲测图：真值已知、图上不印值（逼双方走标定+反算）。

## 目录

```
blindset/
├── original/          原图（柱顶带印值）—— 保存供核对
│   ├── 24_fig3.png        24.pdf 图3（4面板分组柱，抗压强度）
│   └── yansuan_fig4.png   碱与硫酸盐篇 图4（3面板分组柱，抗压强度）
├── erased/            无印值图 —— 手工 PS 擦掉柱顶数字（测试输入）
├── benchmark.csv      真值表
├── erase_values.py    自动擦值脚本（对 hatch 柱无效，留作参考）
└── README.md
```

## benchmark.csv 字段

`figure, panel, panel_name, group, series, value, note`

- series：3d / 7d / 28d（各面板内左→右的柱子顺序）
- value：柱顶印值（= 图真值）。空 = 待填
- note：`正文已验证` = 论文正文给了该值，可信度高；`待填`/`位置存疑` = 需人工核对

## 已知坑（给擦图的人）

- 这两张图的柱子是**深色斜线填充（hatch）**，整根柱子糊成一个大深色连通域，自动擦值会误伤柱子（`erase_values.py` 试过，966 个连通域，多为 hatch 碎片）。**手工擦最稳。**
- 擦的时候**别动坐标轴刻度和轴标题**——标定要用它们。
- 24_fig3 有个坑：a 面板和 b 面板的**图例配色可能不同**（a 里 3d 是红、b 里 28d 是红）——因为 a 是强度随龄期**倒缩**、b 是随龄期**上升**，两边「最高的柱子」都是红的。填/读 series 时留意。
