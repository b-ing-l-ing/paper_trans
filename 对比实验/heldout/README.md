## 真值来源与置信度 ⚠️

### `rm_fig3` —— **高置信，双路确认**

赤泥基这篇 PDF 的图是**矢量图**（柱子是矢量矩形），所以真值有两条独立来源，**逐值吻合**：

1. **柱顶印值**（论文自己写的数）—— CSV 里填的就是这个
2. **矢量几何实测**：柱子矩形高度 ÷ 标定比例（(a) 63.00 pt/MPa、(b) 37.90 pt/MPa，由轴刻度反推）

例：`0.502` vs 印值 `0.50`、`0.223` vs `0.22`、`2.880` vs `2.88`……**35 根全部对到小数点后两位**。
→ 结论：**这组真值可以直接信**，不用你逐个核对（当然核一下更好）。

⚠️ **两个必须知道的坑**：

1. **零高度柱**：图3(a) 的 `w(CS)=5%` 组，**3d = 0** —— 原图**只印了标签「0」、没有柱体**（不是「没做这组」）。
   - CSV 里该行 value 填 **0**
   - 但这根柱**没有柱体可测** → 代码和 LLM 大概率都检不出。**评测时必须先讲清**：这个 0 算不算分母、算不算漏读（建议单列说明，别悄悄扣分）
2. **擦图是程序化做的**（不是 PS）：见下面「擦值方式」

## 擦值方式

| 图 | 方式 | 状态 |
|---|---|---|
| `rm_fig3` | **程序化擦除**：`erase_bar_labels.py`（矢量图专用，可复现） | ✅ 已生成 `erased/rm_fig3.png` |
| `mat_fig2` | 位图，只能 **PS 手工**擦 | ⬜ 待做 |

`erase_bar_labels.py` 原理：柱子=底边贴同一基线的填充矩形；文字=填充色固定近黑 `(0.1367,0.1220,0.1253)` 的 path（柱子只可能是白/浅灰/深灰，**永远撞不上这个色**）→ 每根柱顶上方开窗取交。
实测：35/35 根标签全擦净、**0 处伤到柱体**、轴刻度与图例完好。

踩过的坑（已写进脚本注释）：
- 按「字形大小」过滤必漏——PDF 把字形拆成了 `h=1.6~2.6` 的碎片；
- 窗口下缘必须探到柱顶**下方 6pt**——旋转文字的小数点在字符串末尾，会落在柱顶边缘下。

## 纪律（硬规则，违反 = 实验作废）

这批是**留出集**：

1. **跑完即冻结**（存档带日期），结果禁止用于调参。

3. **一调，它就变回开发集**，无偏性作废。
